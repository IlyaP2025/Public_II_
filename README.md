# Multilayer Perceptron

Реализация многослойного перцептрона для распознавания рукописных букв латинского алфавита с возможностью расширения до RAG-помощника и системы анализа изображений.

## Особенности
- Язык: C++20
- Графический интерфейс: Qt5 (MVC)
- Сборка: Makefile (all, install, uninstall, clean, dvi, dist, tests)
- Две реализации перцептрона: матричная и графовая
- Обучение методом обратного распространения ошибки
- Сохранение/загрузка весов
- Unit-тесты (GTest)
- Поддержка кросс-валидации и метрик качества
- Возможность работы с EMNIST‑letters и пользовательскими BMP‑изображениями
- Конечный автомат для управления процессом обучения в GUI
- Паттерны проектирования: Стратегия, Фасад, Команда, Наблюдатель

## Структура проекта
```text
multilayer_perceptron/
├── libmlp/                     # Ядро — библиотека машинного обучения
│ ├── include/mlp/              # Публичные заголовки (видны потребителям библиотеки)
│ │ ├── core/                   # Абстрактные интерфейсы (IPerceptron, ITrainer, IDataLoader, ...)
│ │ └── exceptions.h            # Иерархия исключений библиотеки
│ ├── src/                      # Внутренняя реализация
│ │ ├── matrix/                 # Класс Matrix и операции линейной алгебры
│ │ ├── activation/             # Функции активации (сигмоида и её производная)
│ │ ├── perceptron/             # Реализации перцептронов
│ │ │ ├── matrix_perceptron     # Матричный многослойный перцептрон
│ │ │ └── graph_perceptron      # Графовый перцептрон (нейроны как узлы)
│ │ ├── trainer/                # Алгоритмы обучения (SimpleTrainer, кросс-валидация)
│ │ ├── data/                   # Загрузчики данных (EMNIST, CSV, нормализация)
│ │ ├── metrics/                # Метрики (Accuracy, Precision, Recall, F1-Score)
│ │ └── serialization/          # Сохранение/загрузка весов
│ └── Makefile                  # Сборка библиотеки libmlp.a
│
├── gui_app/                    # Десктопное приложение (MVC + Qt)
│ ├── view/                     # Представление: окна, вкладки, графики
│ ├── controller/               # Тонкий контроллер и конечный автомат обучения
│ └── main.cpp                  # Точка входа
│
├── tests/                      # Все тесты проекта
│ ├── unit/                     # Unit-тесты (Matrix, forward/backward, метрики)
│ ├── integration/              # Интеграционные тесты (обучение + инференс)
│ └── Makefile                  # Сборка и запуск тестов
│
├── datasets/                   # Открытые датасеты (EMNIST-letters, CSV)
│
├── rag_data/                   # База знаний для будущего RAG-помощника
│ ├── raw/                      # Исходные PDF / книги
│ ├── processed/                # Извлечённый текст (CSV, Markdown)
│ └── index/                    # Векторный индекс FAISS и метаданные
│
├── scripts/                    # Утилиты (парсинг PDF, предобработка, анализ)
├── report/                     # Отчёты (сравнение производительности, графики)
└── Makefile                    # Корневой Makefile (all, install, clean, tests, dvi, dist)
```
