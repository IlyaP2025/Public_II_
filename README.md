# Multilayer Perceptron

Реализация многослойного перцептрона для распознавания рукописных букв латинского алфавита с возможностью расширения до RAG-помощника и системы анализа изображений.

## Особенности
- **Язык:** C++20, компилятор g++
- **GUI:** Qt5 (MVC)
- **Сборка:** Makefile (цели `all`, `install`, `uninstall`, `clean`, `dvi`, `dist`, `tests`, `gui`)
- **Две реализации перцептрона:** матричная (готова) и графовая (в плане)
- **Обучение:** метод обратного распространения ошибки (SGD)
- **Сохранение/загрузка весов** с автоматическим включением архитектуры в имя файла
- **Метрики:** Accuracy, Precision, Recall, F1 (макро-усреднение)
- **Рисование букв мышью** и загрузка BMP‑изображений
- **Конечный автомат** управления обучением (Idle, Training, Paused)
- **Паттерны проектирования:** Стратегия, Фасад, MVC

## Что уже реализовано

### Ядро (`libmlp`)
- **Класс `S21Matrix`** – полная линейная алгебра (сложение, умножение, транспонирование, Apply, Hadamard).
- **Матричный перцептрон** (`MatrixPerceptron`) – прямое/обратное распространение, обновление весов.
- **Загрузчик EMNIST** – чтение CSV, нормализация, разделение на train/test.
- **Загрузчик BMP** – масштабирование 28×28, нормализация (без инверсии).
- **Метрики** – Accuracy, Precision, Recall, F1 (макро).
- **Сериализация весов** – текстовый формат, одна матрица на строку.

### Графический интерфейс
- **Вкладки**
  - **Training** – настройка learning rate, числа эпох, запуск/пауза/остановка, прогресс-бар, лог.
  - **Experiment** – загрузка BMP, рисование мышью, запуск эксперимента на тестовой выборке, вывод метрик.
  - **Settings** – выбор архитектуры (Linear / Manual / Geometric), кнопка Apply, сохранение/загрузка весов.
- **Конечный автомат** состояний обучения (`Idle`, `Training`, `Paused`).
- **Рисование букв** (DrawWidget) – отдельное окно, кисть, кнопка Classify.
- **Авто-имя при сохранении весов** – `weights_784_595_405_216_26.txt`.

## Тесты
- 62 unit-теста (матрица, перцептрон, загрузка EMNIST, метрики).
- Покрытие ключевых модулей >80%.

## Что ещё не реализовано

- **Графовый перцептрон** (`GraphPerceptron`) – второй вариант реализации, требуемый заданием.
- **Кросс-валидация в GUI** – интерфейс есть, но не подключена логика.
- **Визуализация активаций / весов** – тепловые карты, гистограммы.
- **Интеграция с тепловизором** (будущий проект) – интерфейс `IPerceptron` уже готов для добавления новых типов сетей.
- **Полная поддержка BMP‑инверсии** – решается после завершения 20‑эпох обучения.
- **Doxygen‑документация** – цель `dvi` в Makefile пока выводит заглушку.
