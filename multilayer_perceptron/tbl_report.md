# Сравнение производительности матричного и графового перцептронов

Дата тестирования: 07.09.2026

## Характеристики тестового стенда

- **Модель ноутбука:** Sony SVE1512H1RW
- **ОС:** Ubuntu 24.04.4 LTS
- **Ядро:** 7.0.0-30-generic
- **Архитектура:** x86_64
- **Процессор:** Intel Core 3-го поколения (2 ядра, 4 потока)
- **Кэш L3:** 3 MiB
- **Оперативная память:** 15 GiB
- **Накопители:** SSD Kingston 512 ГБ + HDD Seagate 1 ТБ
- **Графика:** Intel HD Graphics 4000 (встроенная)

*Примечание: ноутбук офисного уровня, не оптимизирован для тяжёлых вычислений.*

## Методика измерений

- Архитектура модели: **784 → 595 → 405 → 216 → 26**
- Модель обучена в течение 36 эпох, веса сохранены и загружены в обе реализации.
- Для каждой реализации выполнялись предсказания на **полной тестовой выборке** (17 760 изображений).
- Время фиксировалось с помощью `std::chrono::high_resolution_clock`.
- Основное измерение: **10 повторений**, результат усреднён.
- Контрольные измерения: **1 повторение** и **3 повторения**.
- Для 100 и 1000 запусков суммарное время рассчитано умножением среднего одного прогона на количество повторений (прямое выполнение заняло бы слишком много времени на данном оборудовании).

## Вывод

Графовый перцептрон работает **медленнее** матричного. Среднее время одного прогона по тестовой выборке:

- **матричный:** ~87.0 сек,
- **графовый:** ~136.4 сек.

Замедление графовой реализации объясняется тем, что каждый нейрон представлен отдельным объектом, связи между ними динамические, что увеличивает накладные расходы по сравнению с плотными матричными операциями. Матричный подход эффективнее использует кэш процессора и показывает значительно лучшую производительность на CPU.
